# Accounting System Pro 🚀

نظام محاسبي متكامل يعمل بوضعية Offline-First، مصمم لضمان دقة العمليات المالية وإدارة المخزون.

## 🛠 المكونات التقنية
- `database_setup.py`: تهيئة الجداول (SQLite).
- `main.py`: المنطق البرمجي (عمليات البيع، القفل، والتنبيهات).
- `app_ui.py`: الواجهة الرسومية التفاعلية (Flet).
- `reports.py`: تصدير التقارير بصيغة CSV.

## 🚀 كيفية التشغيل
1. تأكد من تثبيت مكتبة `flet`: `pip install flet`
2. قم بتشغيل قاعدة البيانات أولاً: `python database_setup.py`
3. ابدأ الواجهة الرسومية: `python app_ui.py`

## 🔒 نظام الصلاحيات
- **المدير:** يمتلك وصولاً كاملاً للتقارير، حذف الفواتير، وإدارة المستخدمين.
- **الموظف:** يقتصر عمله على إدخال الفواتير ومراقبة المخزون.
